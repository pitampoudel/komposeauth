Moving files to another bucket

This server copies no file; the providers' own tools do.
  1. Add the new bucket and test it.
  2. Press Send new files here on it, then wait a minute for every server to switch.
  3. Copy everything from the old bucket into the new one under the same names, with rclone copy between any two providers, or gcloud storage rsync / aws s3 sync within one. Run it once more after that minute so nothing written meanwhile is left behind.
  4. On the old bucket, press Files copied to… and choose the new one, then open a few old photos to check. Keep the old bucket listed: it is how this server recognises its old addresses.

Saved addresses are never rewritten. Going back is the same steps the other way, starting with Open from its own bucket on the bucket you return to.
